# Redux Toolkit Practice

A practice repository created to learn and experiment with **Redux Toolkit, React Redux, React Router, and state management concepts in React**.

This repository is focused on understanding how global state works in React applications and how Redux Toolkit simplifies state management.

---

## 🛠️ Tech Stack

* React 19
* Redux Toolkit
* React Redux
* React Router
* Vite
* JavaScript
* Chance.js

---

## 📚 Concepts Practiced

* Redux store configuration
* Redux Toolkit
* `createSlice`
* Actions and reducers
* Global state management
* `useSelector`
* `useDispatch`
* Managing state across components
* Updating and removing state
* React-Redux `<Provider>`
* React Router basics
* Generating dummy data using Chance.js

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd statemangemet
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run the Application

Start the Vite development server:

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

## 🎯 Purpose

This repository is **not a production project**. It is a hands-on practice repository created to strengthen understanding of **Redux Toolkit and state management in React**.

The concepts learned here can be applied to larger React/MERN applications where multiple components need to share and manage application state.
